# Synthetic workforce dashboards — native Power BI

Three sanitized native Power BI project adaptations with wholly invented demonstration data. These are PBIP/PBIR/TMDL projects, not HTML replacements or binary PBIX exports.

| Folder | Entry point | Scope |
|---|---|---|
| `direct-workforce` | `DirectWorkforce.pbip` | Direct-workforce overview, movement and attrition |
| `combined-workforce` | `Combined Workforce.pbip` | Combined-workforce headcount and movement |
| `fiscal-workforce` | `Fiscal Workforce.pbip` | Fiscal workforce planning and movement |

## Open locally

Keep each `.pbip` file beside its companion `.Report` and `.SemanticModel` folders. Open it in a compatible Power BI Desktop installation and refresh the embedded synthetic tables. Read the project-specific README first. No original datasets, company connections, credentials, cached data, company images, exports or prior Git history are included.

## What this demonstrates

Native report layouts, field bindings and reviewed generic calculations, backed by deterministic fictional scenarios. Source-system extraction and organization-specific mappings are not reproduced. Branding, saved filters/selections and images have been removed or neutralized. Some legacy relationships and narrative calculations were changed; each README documents its actual fidelity losses.

## Validation limits

Automated tests, JSON schema checks and offline Microsoft TOM model deserialization were performed. These are not engine execution tests. **Power BI Desktop opening, refresh, DAX/M evaluation and visual rendering have not been tested.** Treat these as statically validated working copies, not certified dashboards. The synthetic rows illustrate behavior; they are not real workforce statistics or benchmarks.

Data sanitization is not an ownership transfer. No open-source license is assigned. Redistribution of the underlying report design and calculations requires the appropriate rights. Private source-selection, build and audit materials are deliberately excluded from this repository.
